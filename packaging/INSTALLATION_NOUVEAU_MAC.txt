SUITE CL — INSTALLATION SUR UN NOUVEAU MAC
===========================================

CE KIT CONTIENT

1. Installer la Suite CL.app
   Une application d'installation graphique. Python et les bibliothèques
   nécessaires sont déjà inclus : aucune installation Python ou commande pip
   n'est nécessaire sur le Mac cible.

2. Max for Live à installer
   - XFADER OSC BRIDGE v8
   - LTC Display v2.0 Remote Config
   - Paradis Latin AutoScene
   - Paradis Latin AutoScene - Live 10

3. AbletonOSC CL — Live 11 et Live 12
   Version validée avec les routes utilisées par CL Audio Controller.

4. CL Arrangement Builder Live et CL MIDI Console Monitor
   Proposés séparément dans l'écran de sélection de l'installateur.


INSTALLATION AUTOMATIQUE RECOMMANDÉE

1. Fermer complètement Ableton Live.
2. Double-cliquer sur « Installer la Suite CL.app ».
3. Si macOS refuse le premier lancement :
   clic droit sur le fichier > Ouvrir > Ouvrir.
4. Choisir le rôle de ce Mac, puis Ableton Live 12 si le rôle le demande.
5. Relancer Ableton Live.
6. Ouvrir Réglages > Link, Tempo et MIDI.
7. Choisir AbletonOSC comme surface de contrôle si CL Audio Controller a été
   installé.
8. Ouvrir les applications depuis le dossier Applications de votre compte.
9. Conserver le profil Local pour une installation sur un seul Mac.


RÔLES RTP-MIDI

- Mac Télécommande — RTP émetteur-récepteur : installe Show Control, la
  découverte automatique Bonjour et les retours MIDI des consoles. La liaison
  réseau démarre automatiquement à l'ouverture de session.
- Mac Ableton Lecteur — RTP émetteur-récepteur : installe AbletonOSC, LTC,
  X-Fader et l'agent RTP-MIDI bidirectionnel. L'agent démarre automatiquement à
  l'ouverture de session.
- Simulateur de console RTP : outil d'essai manuel qui simule les retours
  Program Change CL5 sur le canal 1 et QL1 sur le canal 2.

Les noms des ordinateurs ne sont pas inscrits en dur dans le kit : les autres
Macs sont découverts sur le réseau par Bonjour.


EMPLACEMENTS UTILISÉS

Application :
~/Applications/CL Audio Controller.app

AbletonOSC :
~/Music/Ableton/User Library/Remote Scripts/AbletonOSC

Max for Live Live 12 :
~/Music/Ableton/User Library/Presets/Audio Effects/Max Audio Effect/
et ~/Music/Ableton/User Library/Presets/MIDI Effects/Max MIDI Effect/

L'installation dans le compte utilisateur évite de demander un mot de passe
administrateur. Une ancienne installation n'est jamais supprimée : elle est
renommée avec la date et l'heure avant remplacement.


COMPATIBILITÉ

- macOS : Apple Silicon et Intel (application universal2)
- Ableton Live 12 : configuration principale, AbletonOSC CL fourni et validé
- Ableton Live 11 : utilise le même ensemble de composants que Live 12
- Ableton Live 10 : ne pas installer l'AbletonOSC fourni sans validation ;
  l'installateur ne propose que « Paradis Latin AutoScene - Live 10 ».
- Max for Live est nécessaire pour les périphériques LTC et crossfader.


RÉSEAU

Mode Local :
- AbletonOSC reçoit sur UDP 11000
- CL Audio Controller reçoit les réponses sur UDP 11001
- LTC arrive sur UDP 63123
- le pont crossfader écoute sur UDP 9001

Mode Distant :
- renseigner l'adresse du Mac Ableton dans le panneau de contrôle ;
- autoriser les connexions entrantes dans le pare-feu macOS si demandé ;
- utiliser de préférence un réseau Ethernet dédié.


VÉRIFICATION

Le fichier SHA256SUMS.txt permet de contrôler l'intégrité du kit complet.


SÉCURITÉ MACOS

Cette version n'est pas encore notarisée par Apple. Au premier lancement,
utiliser clic droit > Ouvrir si Gatekeeper affiche un avertissement.
Ne désactivez pas globalement les protections de macOS.


CL ARRANGEMENT BUILDER LIVE

CL Arrangement Builder Live reste une application indépendante. L'installateur
graphique permet de l'installer seule ou avec le reste de la suite.
