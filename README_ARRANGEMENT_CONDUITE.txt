Arrangement - Mode conduite

Cette version modifie l'onglet Arrangement pour un usage spectacle :

1. Les Locators/Cue Points du Set Ableton sont récupérés automatiquement via AbletonOSC.
2. La liste déroulante permet de choisir le repère à préparer.
3. Le bouton LECTURE saute au repère choisi puis lance la lecture.
4. Le bouton Préparer saute au repère choisi sans lancer la lecture.
5. Les boutons Stop, Pause, Début, Repère précédent et Repère suivant restent disponibles.

Le fichier arrangement_markers.json reste présent uniquement comme solution de repli si AbletonOSC ne renvoie pas les Locators du Set.
