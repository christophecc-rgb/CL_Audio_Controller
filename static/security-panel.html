Exploitation

—

Appairage = appareil connu · rôle = droits · armement = commandes actives. ShowQ reste accessible quand les commandes sont désarmées.

Scanner avec Safari sur l’iPhone. Cet accès ouvre ShowCue et réutilise l’autorisation existante. Il ne crée aucune association et n’accorde aucun droit. Si des commandes nécessitent une autorisation, associer l’iPhone via Première configuration iPhone et approuver sa demande sur le Mac.

Appareils appairés

Rôle et autorisation conservés. Les droits se modifient en mode configuration ; la révocation reste disponible en spectacle.

1 — Préparer la connexion sécurisée

Déverrouiller l’administration, puis autoriser le mode configuration. Le nom de ce Mac est proposé automatiquement.

2 — Vérifier l’iPhone

Connecter l’iPhone au même réseau. Scanner le QR de test avec Safari, puis confirmer sur l’iPhone. Cette page suit automatiquement la confirmation.

Ouvrir le test sur l’iPhone

Première utilisation : installer la confiance sur l’iPhone

Scanner ce QR pour télécharger le certificat public. Les clés privées restent sur le Mac.

Télécharger le profil public (AirDrop possible)

Dans Réglages → Général → VPN et gestion de l’appareil, installer « Confiance CL Show Control ». Comparer l’empreinte affichée aux détails du certificat. Puis Réglages → Général → Informations → Réglages des certificats : activer la confiance totale pour cette CA.

Aide Apple

3 — Ajouter la télécommande

Scanner le QR, saisir le nom sur l’iPhone, puis approuver la demande ici. L’autorisation permanente conserve l’appareil et son rôle après redémarrage. Les rôles de commande sont armés par défaut ; un désarmement explicite reste mémorisé.
